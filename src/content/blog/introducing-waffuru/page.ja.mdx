## なぜ、*今*なのか

インテリジェンスへの需要に限りはありません。それを支える資源には、限りがあります。推論を拡大するには、新しいデータセンターと追加の電力だけでは足りません。計算とエネルギーの 1 単位ごとから、より多くの有用な仕事を引き出す必要があります。次の世代のインフラは、コスト、エネルギー需要、環境負荷が増えるよりも速く、インテリジェンスへのアクセスを広げなければなりません。

電力が上限なら、まだ動かせる変数は効率です。1 ワットあたりのトークン数と、ワークロードあたりのコスト。この 2 つは、私たちが磨き続けられる指標です。効率が上がっても、需要は縮みません。得られた余裕は、さらなるインテリジェンスに使われます。古くからあるジェボンズのパラドックスです。だから、計算への欲求は増える一方です。

曲線のもう一方の端も動いています。2 年ほどのうちに、すでに持っているハードウェアで動くモデルが、意味のある仕事をこなせるほど十分に良くなると、私たちは考えています。ムーアの法則と AI の急速な進歩が、積み重なり続けているからです。

誰もがパーソナルアシスタントを、あるいはそのチームを持ち、アシスタント同士が会話するようになると、私たちは見ています。人は主体性を求めます。だからアシスタントは、信頼できる自分自身の延長でなければなりません。役に立ち、親しみやすく、怖くない存在であること。その関係は、スマートフォンとの関係と同じくらい個人的なものになるでしょう。それは、住む場所、収入、資格や肩書きに左右されてはなりません。どこにいても稼ぐ力を高めるには、インテリジェンスへの開かれた、ローカルなアクセスが必要です。

## 私たちが*つくっている*もの

製品は 4 つ。ハードウェアに近いほうから順に番号を振っています。Iron がカーネルをコンパイルし、Butter がその上でモデルを動かします。Waffle が GPU を見守り、Syrup が取り組んでいたことを覚えています。どれも単体で使え、組み合わせれば、ローカルファーストのパーソナルアシスタントの土台になります。

### Iron、カーネル

[Iron](/products/iron) は、ひとつのカーネル定義から 4 つのバックエンドへ、という製品です。カーネルは、Rust に埋め込む DSL で書きます。それは共通の IR に落とされ、さらに Metal、CUDA、HIP/ROCm、Vulkan SPIR-V へと変換されます。バージョン管理された C と Rust の ABI により、すでにお持ちのホストから呼び出せます。現在のカーネル宣言は約 1,139 個で、HIP と Vulkan のテストコーパスは、4,164 件中 4,164 件がビット単位で一致しています。`exp` カーネルの定義は、これですべてです。

```rust title="unary.rs"
#[kernel(bench(op = "unary", subop = "exp", tol = 1e-4))]
pub fn iron_exp<T>(a: Tensor<T>, out: Tensor<T>) {
    let idx = program_id(0);
    store(out[idx], exp(load(a[idx])));
}
```

あなたが書くのはここまで。残りは Iron が書きます。

### Butter、エンジン

[Butter](/products/butter) は、Python 不要のモデルサービングです。Apple シリコンでは Metal 上の Swift、CUDA などでは Rust で書かれています。Hugging Face からモデルを直接、変換なしで読み込み（safetensors、MLX、JANG、GGUF）、2〜8 ビットの量子化チェックポイント、ハイブリッドモデルと Mixture of Experts モデル、量子化された KV キャッシュを動かします。`butter serve` は OpenAI API で話し、ストリーミング、ツール呼び出し、投機的デコーディング、LoRA に対応します。テキスト、ビジョン、音声認識、音声合成、オムニの各モデルが動きます。Python も JIT もありません。

### Waffle、コントロールプレーン

[Waffle](/products/waffle) は、すべての GPU と、その上で動くすべてのエンジンを見せてくれます。デスクの下の 1 台から、フリートを貸し出すネオクラウドまで。各ホストでは小さな Rust 製サイドカーが動き、署名付きテレメトリを報告します。Butter、vLLM、SGLang、llama.cpp など OpenAI 互換のサーバーと連携するので、ロックインはありません。

### Syrup、記憶

[Syrup](/products/syrup) は、あなたの AI が、取り組んでいたことを覚えるための仕組みです。ノートとコードに対するローカル検索を行い、埋め込みを TurboQuant+ で圧縮し、キーワード検索とベクトル検索で探して、結果を MCP 経由で出典付きで返します。

## 私たちが*大切にする*こと

私たちは価値観を書き出しました。それを根拠に、私たちに責任を問えるようにするためです。そのうちのいくつかは、この記事にも反映されています。正直さとは、状況、リスク、ミス、限界を率直に伝えることです。だから、下の「私たちの現在地」の節は具体的に書いています。科学的手法とは、仮説を立て、測定し、再現することです。意見よりベンチマークだからです。自律とは、人々に時間を取り戻すシステムをつくることです。機会の平等とは、インテリジェンスへのアクセスが、住む場所、財力、資格や肩書きに左右されてはならない、ということです。

ここから、2 つの制約が導かれます。私たちがつくるものは、コンシューマー向けのハードウェアで動かなければならないこと。そして、あなたのデータは、あなたがオプトインしない限り、あなたのマシンにとどまること。もうひとつ、楽しむことも大切にしています。難しい問題にふさわしいのは、仕事を楽しめるチームだからです。
